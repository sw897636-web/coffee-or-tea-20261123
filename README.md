One letter, A for coffee, written for the
[make.fun](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0)
bounty "One Letter: Coffee or Tea".

> A

## Why A

The judge weighs vivid first, then funny, then truer. Coffee's cultural
image is bolder, louder and more joke-dense ("don't talk to me before
coffee") than tea's calm, gentle one, so A lands as the more vivid and
funnier single-letter answer.

## How it works

`main.ts` (Node 22, standard library only) writes the letter to the output
directory, byte for byte — `MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`.
Run it with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The output `entry.txt` is exactly one character, `A`, with no newline, and
identical on every run.
